# MICRONAS ENGINE v5

Fully Autonomous Local AutoML Neural Architecture Search Platform.

## Features
- Deep Learning Framework: PyTorch
- AutoML NAS Search Strategies: Evolutionary algorithms, DARTS, Bayesian Optimization
- Hardware Constraints: Local Single GPU (GTX 1050), CPU-only
- GUI: PySide6 Desktop Application

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python main.py
   ```
